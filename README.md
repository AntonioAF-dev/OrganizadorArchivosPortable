# Organizador de Archivos Portable

[![Descargar Release](https://img.shields.io/badge/Descargar-Release_v1.0.0-blue?style=for-the-badge&logo=github)](https://github.com/AntonioAF-dev/OrganizadorArchivosPortable/releases/tag/AFyloX_v1.0.0)

Un sistema portable para la organización de archivos, desarrollado usando PHP, HTML, CSS, JavaScript y empaquetado para funcionar sin instalaciones adicionales.

## Características

- **Totalmente Portable**: No requiere instalación de un servidor web ni de PHP en el sistema operativo. Viene con su propio motor integrado.
- **Interfaz Web**: Acceso a través de una interfaz de usuario limpia y fácil de utilizar.
- **Gestión Local**: Ideal para procesar y organizar archivos de manera local utilizando la potencia de PHP de fondo.

## Cómo usar el programa (Versión Portable)

Para usar la versión completamente funcional y lista para usar:

1. Haz clic en el botón de **Descargar Release** en la parte superior.
2. Descarga el archivo comprimido (ej. `OrganizadorArchivosPortable-v1.0.0.zip`) que se encuentra en la sección de **Assets** al final de esa página.
3. Extrae el archivo en cualquier carpeta de tu computadora.
4. Ejecuta el archivo principal **`AFyloX.exe`** y el programa se abrirá automáticamente.

## Código Fuente

Este repositorio contiene el código fuente de la aplicación web. Si eres desarrollador y deseas explorar o modificar el código, puedes hacerlo editando los archivos dentro de la carpeta `www/AFyloX` de tu versión descargada. No necesitas instalar PHP Desktop manualmente, ya que todo el entorno ya está incluido en la versión del Release.
